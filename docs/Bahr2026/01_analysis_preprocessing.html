Loading the preprocessed daily alcohol consumptoin [AC] EMA data. Documentation is currently in the process of publication and can be made available upon request.

The loaded data frame includes the following variables:

  • Subj ~ Redcap ID
  • center ~ recruitment center
  • date ~ date of observation
  • ref ~ alcohol consumption reference day
  • date_ref ~ date of consumption
  • time ~ datetime of observation
  • alc_g ~ alcohol consumption (per Subj, date_ref)
  • alc_b ~ drinking days
  • imp01 ~ cases with “removing multiple daily assessments”
  • imp02 ~ cases with “removing gestern/vorgestern overlap”
  • imp03 ~ cases with “correcting conflicting information”
  • imp04 ~ cases with “imputations for missing amounts”
  • imp05 ~ cases with “0 amounts coded as non drinking days”

3 EMA data preprocessing

3.1 holiday

For holiday variables bank holidays were identified based on the location of the recruitment center

  • all ~ Neujahr; Tag der Arbeit; Tag der deutschen Einheit; 1. Weihnachtstag; 2. Weihnachtstag; Karfreitag; Ostersonntag; Ostermontag; Christie Himmelfahrt; Pfingstsonntag; Pfingstmontag
  • berlin only ~ Internationaler Frauentag
  • dresden only ~ Reformationstag
  • mannheim only ~ Reformationstag; Heilige drei könige; Fronleichnam

Utilised dates can be found in the codefold below. Holiday-related AC days were coded as the day before a bank holiday generating the follwong holiday related variables:

  • holiday ~ holiday [1;0]
  • hd ~ day before holiday contrast [no holiday = hd0; holiday = hd1]

3.2 weekday

Weekday for the analysis was coded to differetiate between days before a weekendday (i.e. Friday & Saturday) and days not followed by a weekendday.

The following Variables were generates:

  • weekday_num ~ weekday numerical (Monday == 1 - Sunbday == 7)
  • weekday ~ weekday categorical
  • wd ~ identifications of days followed by a weekendday [weekday == wd0, weekendday == wd1]

3.3 Covid

Two hard lockdowsn were idenfied from 2020-03-22 to 2020-05-06 and 2020-12-16 to 2021-03-03,

  • covid ~ har lockdown identification [no hard lockdown == ld0, hard lockdown == ld1]

3.4 Month and yearday

To estimate annual variation of AC a three factor variable was generate based on months as well as a continuous variable estmating the annual variation in AC across one iteration of a sinus curve. This approach is documented and verified with temperature data in the script XXXXXXXXX.

The following varibles were generates

  • month ~ month catrgoricat
  • month_num ~ month numerical (January == 1 - December == 12)
  • yearday ~ day of the year centered at 1st of january
  • jd ~ three factor variable [January; December; other]
  • yd_sin ~ yearday fitted acruss a sinus curve centered at yearday == 248 (6th September)

3.5 Day since assessment start

Days were counted sins the start of data assessment for each Subj. The follwoing variables were generated:

  • day ~ day since the first assessment
  • d1 ~ day centered at the group mean (162.7572), linear
  • d2 ~ day quadratic
  • d3 ~ day cubic

3.6 Age

Age was estimate continuously based on each time od AC.

  • age_co ~ day since the first assessment
  • age_co_g ~ age groups using age at enrollment ([16:32]; [33:49]; [50:66])
  • a1 ~ age_co centered at the group mean (39.2419 years), linear
  • a2 ~ age_co quadratic
  • a3 ~ age_co cubic

3.7 Alcohol consumption

Alcohol consumption was coded differentiation between consumption day frequency and consumed amounts on consumption day.

For consumed amounty a boxcox analysis was implemented to identify transformation to approach a more normas distribution.

Boxcox analysis suggests log transformation of consumed amounts. Accordingly, the following variables were defined:

  • alc_b ~ consumption days
  • alc_g ~ grams consumed on consumption days
  • alc_l ~ log transformed alc_g

  paste0(2020:2024, "-05-01"), # Tag der Arbeit
  paste0(2020:2024, "-10-03"), # Tag der deutschen Einheit
  paste0(2020:2024, "-12-25"), # 1. Weihnachtstag
  paste0(2020:2024, "-12-26"), # 2. Weihnachtstag
  "2020-04-10", "2021-04-02", "2022-04-15", "2023-04-07", "2024-03-29", # Karfreitag
  "2020-04-12", "2021-04-04", "2022-04-17", "2023-04-09", "2024-03-31", # Ostersonntag
  "2020-04-13", "2021-04-05", "2022-04-18", "2023-04-10", "2024-04-01", # Ostermontag
  "2020-05-21", "2021-05-13", "2022-05-26", "2023-05-18", "2024-05-09", # Christie Himmelfahrt
  "2020-05-31", "2021-05-23", "2022-06-05", "2023-05-28", "2024-05-19", # Pfingstsonntag
  "2020-06-01", "2021-05-24", "2022-06-06", "2023-05-29", "2024-05-20" # Pfingstmontag
))

holy_B <- as_date(c(
  paste0(2020:2024, "-03-08") # Internationaler Frauentag
))

holy_D <- as_date(c(
  paste0(2020:2024, "-10-31") # Reformationstag
))

holy_M <- as_date(c(
  paste0(2020:2024, "-01-06"), # Reformationstag
  paste0(2020:2024, "-01-11"), # Heilige drei könige
  "2020-06-11", "2021-06-03", "2022-06-16", "2023-06-08", "2024-05-30" # Fronleichnam
))

h_b <- c(holy_all-1, holy_B-1)
h_d <- c(holy_all-1, holy_D-1)
h_m <- c(holy_all-1, holy_M-1)

dat <- data_alc |> 
  select(Subj, date_form = date, date = date_ref, ref, alc_b, alc_g) |> 
  left_join(Data_subj |> select(Subj, center, group, incl, gender, bdate, mass, aud)) |> 
  group_by(Subj) |> 
  mutate(day = as.numeric(date - min(date)),
    weekday_num = wday(date, week_start = 1),,
    weekday = factor(weekdays(date), levels = c("Monday", "Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday")),
    month = factor(months(date), levels = c("January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December")),
    month_num = month(date),
    yearday = yday(date),
    covid = case_when(date > as_date("2020-03-22") & date < as_date("2020-05-06") ~ 1,
                      date > as_date("2020-12-16") & date < as_date("2021-03-03") ~ 1,
                      TRUE ~ 0),
    holiday = case_when(center == "B" & as_date(date) %in% c(holy_all, holy_B) ~ 1,
                        center == "D" & as_date(date) %in% c(holy_all, holy_D) ~ 1,
                        center == "M" & as_date(date) %in% c(holy_all, holy_M) ~ 1,
                        TRUE ~ 0),
    hd = case_when(center == "B" & as_date(date) %in% h_b ~ "hd1",
                   center == "D" & as_date(date) %in% h_d ~ "hd1",
                   center == "M" & as_date(date) %in% h_m ~ "hd1",
                   TRUE ~ "hd0"),
    age_co = as.numeric((date-bdate)/365.25),
    age_co_g = case_when(min(age_co) < 33 ~ "[16:32]",
                         min(age_co) >= 33 & min(age_co) < 50 ~ "[33:49]",
                         min(age_co) >= 50 ~ "[50:66]")) |> 
  ungroup() |> 
  mutate(
    alc_l = log(alc_g+1),
    alc_l2 = ifelse(alc_b == 1, log(alc_g), NA),
    wd = ifelse(weekday %in% c("Friday","Saturday"), "wd1", "wd0"),
    ld = paste0("ld", covid),
    a1 = scale(age_co, scale = F)[,1],
    a2 = a1^2,
    a3 = a1^3,
    d1 = scale(day, scale = T)[,1],
    d2 = d1^2,
    d3 = d1^3,
    jd = case_when(month %in% c("January", "December") ~ month, 
                   TRUE ~ "other"),
    yd_sin = sin((248+yearday)/365*2*pi)) |> 
  group_by(Subj) |> 
  mutate(mday = max(day)) |> 
  ungroup()
